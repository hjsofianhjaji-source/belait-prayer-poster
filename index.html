Tetapan poster

V1.5.1 menyimpan jadual CSV dalam browser ini dan mengisi waktu secara automatik apabila tarikh ditukar. Import baharu menggantikan jadual lama. Data kekal pada peranti ini sahaja.

Format V1.5.1: tarikh,hijri,kaedah,sumber,imsak,subuh,syuruk,dhuha,zohor,asar,maghrib,isyak. Pilih kaedah waktu yang sepadan dengan data CSV. Fail hanya diproses dalam browser.

V1.5.1: Taip 0437 atau 04:37; aplikasi akan menyusun format HH:MM. Masukkan waktu daripada jadual rasmi KHEU. Pilihan waktu asas akan ditambah 3 minit secara automatik untuk Belait. Jangan tambah 3 minit dua kali. Tarikh Hijrah mesti disemak. Tiada pengambilan data rasmi secara automatik lagi. CSV perlu mengandungi kolum kaedah (base/belait) untuk mengelakkan penambahan 3 minit dua kali. Semak tarikh Hijrah dan sumber rasmi sebelum menyimpan.
